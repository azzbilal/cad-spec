# Smoke 3 audit: `jkqd5k12g1g5kvqyhmfg012k`

## Summary (five lines)

1. **Root cause, 99% confidence:** the Hosted Training env image lacks `libGL.so.1`; CadQuery cannot import, so cad-spec cannot score geometry. Source: indexed env-server logs for all three tiers.
2. Verifiers converts the scorer exception to reward **0.0**, and the enforced zero-advantage filter drops flat groups. Source: env-server logs; installed verifiers 0.3.1 `rubric.py:199-218,319-350`.
3. Repeated scorer-worker startups block synchronous reward calls on env-server async loops; the L4 shutdown trace is inside the 120-second startup wait. Source: L4 log; `measure.py:928-951`.
4. The immediate runtime fix is in **Prime's Linux image or its environment provisioning**: install the CadQuery system libraries already listed in `Dockerfile:13-17`. A cad-spec fail-fast preflight would make recurrence visible at startup.
5. The run was `STOPPED` after zero training tokens and $0.03 inference spend. No code, config, registration, or published artifact was changed during this audit. Source: `prime train get` and `prime train usage`.
