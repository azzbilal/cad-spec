# Audits

Independent audits run by a separate agent (read-only on Prime, no paid
action, no access to the test split). Their reports are evidence; nothing in
this folder is applied to the environment, the scripts or the configs.

| File | What it is | Status |
|---|---|---|
| `smoke3-report.md` | Why the third smoke test completed no step (missing `libGL.so.1` on the training image) | Findings acted on in cad-spec 0.4.5 (Amendment 3) |
| `gl-bundle-review.md` | Review of the 0.4.5 GL-fallback bundle | Findings acted on in the 0.4.5 follow-up commit |
| `run1-cost-report.md` | Why training run 1 cost 2.8x per step what the smoke test predicted (5.5x late), with per-step reconstruction, cost model and ranked guardrails | Report, 2 October 2026 |
| `run1-result-integrity.md` | Whether the training run 1 result is real: reproducibility, determinism, conformity, leakage, reward hacking (code hygiene, template analysis, independent geometry check, perturbations) | Report, 2 October 2026: survives with caveats |
| `scratch/run1_*.py`, `scratch/run1-*.json` | Scripts and outputs behind the integrity report (re-scoring, geometry, perturbations, leakage) | Evidence |
| `reconstruction.json`, `extra-analysis.json`, `run-steps.csv`, `smoke-steps.csv`, `reconstructed-tables.md` | Numbers behind the cost report, regenerated by `scratch/reconstruct_cost.py` and `scratch/extra_analysis.py` from the archived snapshots | Evidence |
| `sources/` | Copies of the Prime CLI and prime-rl source read by the audit, with hashes | Evidence |
| `scratch/` | The audit's own scripts, including offline guard and preflight candidates and their mocked tests | Audit tooling, not project scripts |
| `guardrails-proposed.patch` | Spend guard, preflight check and related changes | **PROPOSED, NOT APPLIED.** To be reviewed, tested and registered before any future paid run; nothing under `scripts/` or `configs/` uses it |

Reproduce the cost report's numbers (Git Bash):

```bash
source "$HOME/cadspec.sh"
export PYTHONIOENCODING=utf-8 PRIME_DISABLE_VERSION_CHECK=1
python audit/scratch/reconstruct_cost.py
python audit/scratch/extra_analysis.py
python audit/scratch/test_guard_offline.py
```
